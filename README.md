# VangtiChai (ভাঙতি চাই)

An Android application built with Java and Android Studio that calculates the optimal breakdown of Bangladeshi Taka (BDT) currency notes and coins for any given monetary amount.

---

## Features

* **Instant Currency Breakdown:** Calculates the exact count of standard BDT notes (1000, 500, 200, 100, 50, 20, 10, 5, 2, and 1 Taka) required for any entered amount.
* **Clean User Interface:** Designed with a straightforward layout for quick inputs and easy readability of results.
* **Lightweight & Efficient:** Developed natively using Java in Android Studio for fast performance on Android devices.

---

## Getting Started

### Prerequisites

* [Android Studio](https://developer.android.com/studio) installed on your machine.
* Android SDK compatible with your target API level.

### Installation

1. Clone the repository or download the source code:
```bash
git clone https://github.com/anishamahjabin/CSE489_AndrioedApp_vangtiChai.git

```


2. Open **Android Studio** and select **Open an Existing Project**.
3. Navigate to the cloned directory and select the project.
4. Allow Gradle to sync and build the project.
5. Run the app on an Android emulator or a connected physical device.

---

## Usage

1. Open the **VangtiChai** app on your mobile device.
2. Enter the total amount in Bangladeshi Taka (BDT) into the input field.
3. Tap the calculate button to instantly view the breakdown of required currency notes and coins.
